Multinomial Logistic Regression

Given dataset X={(xi,yi)}i=1NX = \{ (x_i, y_i) \}_{i=1}^NX={(xi​,yi​)}i=1N​ where xi∈Rnx_i \in \mathbb{R}^nxi​∈Rn and yi∈{1,2,…,C}y_i \in \{ 1,2,\ldots,C \}yi​∈{1,2,…,C}, the Multinomial Logistic Regression model states that the likelihood of the input xxx belonging to class y=cy=cy=c is:

P(y=c∣x,Θ,B)=exp⁡(zc)∑κCexp⁡(zκ) ;zκ=xTθκ+βκP(y = c \mid x, \Theta, \mathcal{B}) = \frac{\exp(z_c)}{\sum^C_\kappa \exp(z_\kappa)} \space ; \quad z_\kappa = x^T \theta_\kappa + \beta_\kappa \quadP(y=c∣x,Θ,B)=∑κC​exp(zκ​)exp(zc​)​ ;zκ​=xTθκ​+βκ​
Block
  • Where Θ={θ1,θ2,…,θC}\Theta = \{ \theta_1, \theta_2, \ldots, \theta_C \}Θ={θ1​,θ2​,…,θC​} are the weights and B={β1,β2,…,βC}\mathcal{B} = \{ \beta_1, \beta_2, \ldots, \beta_C \}B={β1​,β2​,…,βC​} are the biases and they make up the model’s parameters.
  • The set Z={z1,z2,…,zC}Z = \{ z_1, z_2, \ldots, z_C \}Z={z1​,z2​,…,zC​} are called the logits for each of the CCC classes, which contains the linear combinations of the input xxx with the weights and biases.
  • The expression exp⁡(zc)∑κCexp⁡(zκ)\frac{\exp(z_c)}{\sum^C_\kappa \exp(z_\kappa)}∑κC​exp(zκ​)exp(zc​)​ is the ccc-th element of P={P(y=1∣x,Θ,B),…,P(y=C∣x,Θ,B)}\mathcal{P} = \{ P(y=1 \mid x, \Theta, \mathcal{B}), \ldots, P(y=C \mid x, \Theta, \mathcal{B}) \}P={P(y=1∣x,Θ,B),…,P(y=C∣x,Θ,B)} produced by the Softmax Function, in nature it maps the CCC linear combinations ZZZ of the input xxx and the weights Θ\ThetaΘ and biases B\mathcal{B}B to a probability distribution that sums up to 1. In other word, the softmax function takes Z∈RCZ \in \mathbb{R}^CZ∈RC and produces P∈RC\mathcal{P} \in \mathbb{R}^CP∈RC such that ∑cCP(y=c∣x,Θ,B)=1\sum_c^C P(y=c \mid x, \Theta, \mathcal{B}) = 1∑cC​P(y=c∣x,Θ,B)=1.

Our goal is to optimize the parameters Θ\ThetaΘ and B\mathcal{B}B, given MLE equation:

L(Θ,B)=∏i=1N∏c=1C(exp⁡(xiTθc+βc)∑κ=1Cexp⁡(xiTθκ+βκ))1[yi=c]L(\Theta, \mathcal{B}) = \prod^N_{i=1} \prod^C_{c=1} \left( \frac{\exp(x_i^T \theta_c + \beta_c)}{\sum_{\kappa=1}^C \exp(x_i^T \theta_\kappa + \beta_\kappa)} \right)^{1[y_i=c]} \quadL(Θ,B)=i=1∏N​c=1∏C​(∑κ=1C​exp(xiT​θκ​+βκ​)exp(xiT​θc​+βc​)​)1[yi​=c]
Block
  • Where 1[yi=c]1[y_i=c]1[yi​=c] is an indicator function that equals 1 if yi=cy_i = cyi​=c and 0 otherwise.

We take the Log Likelihood to simplify the calculation of MLE:

log⁡L(Θ,B)=∑i=1N∑c=1C1[y1=c]log⁡(exp⁡(xiTθc+βc)∑κ=1Cexp⁡(xiTθκ+βκ))=∑i=1N∑c=1C1[y1=c](xiTθc+βc−log⁡(∑κ=1Cexp⁡(xiTθκ+βκ)))\begin{gather*} \log L(\Theta, \mathcal{B}) = \sum^N_{i=1} \sum_{c=1}^C 1[y_1=c] \log \left( \frac{\exp(x_i^T \theta_c + \beta_c)}{\sum_{\kappa=1}^C \exp(x_i^T \theta_\kappa + \beta_\kappa)} \right) \quad \\[15pt] = \sum^N_{i=1} \sum_{c=1}^C 1[y_1=c] \left( x_i^T \theta_c + \beta_c - \log \left( \sum_{\kappa=1}^C \exp(x_i^T \theta_\kappa + \beta_\kappa) \right) \right) \quad \end{gather*}logL(Θ,B)=i=1∑N​c=1∑C​1[y1​=c]log(∑κ=1C​exp(xiT​θκ​+βκ​)exp(xiT​θc​+βc​)​)=i=1∑N​c=1∑C​1[y1​=c](xiT​θc​+βc​−log(κ=1∑C​exp(xiT​θκ​+βκ​)))​
Block

To maximize the MLE, we maximize the Log Likelihood, which is equivalent to minimizing the negative Log Likelihood, thus we define the cost function:

J(Θ,B)=−1Nlog⁡L(Θ,B)\begin{gather*} J(\Theta, \mathcal{B}) = -\frac{1}{N} \log L(\Theta, \mathcal{B}) \end{gather*}J(Θ,B)=−N1​logL(Θ,B)​
Block

We use Gradient Descent to solve the optimization problem iteratively:

  • Step 1: Initialize parameters randomly: Θ,B\Theta, \mathcal{B}Θ,B.
  • Step 2: Calculate the Gradient of J(Θ,B)J(\Theta, \mathcal{B})J(Θ,B) with respect to each of the logit’s weights θc\theta_cθc​ and biases βc\beta_cβc​:
∂J∂θc=−1N∑i=1N(1[yi=c]−exp⁡(xiTθc+βc)∑κ=1Cexp⁡(xiTθκ+βκ))xi∂J∂βc=−1N∑i=1N(1[yi=c]−exp⁡(xiTθc+βc)∑κ=1Cexp⁡(xiTθκ+βκ))\begin{gather*} \frac{\partial J}{\partial \theta_c} = -\frac{1}{N} \sum_{i=1}^N \left(1[y_i=c] - \frac{\exp(x_i^T \theta_c + \beta_c)}{\sum_{\kappa=1}^C \exp(x_i^T \theta_\kappa + \beta_\kappa)}\right)x_i \quad \\[15pt] \frac{\partial J}{\partial \beta_c} = -\frac{1}{N} \sum_{i=1}^N \left(1[y_i=c] - \frac{\exp(x_i^T \theta_c + \beta_c)}{\sum_{\kappa=1}^C \exp(x_i^T \theta_\kappa + \beta_\kappa)}\right) \end{gather*}∂θc​∂J​=−N1​i=1∑N​(1[yi​=c]−∑κ=1C​exp(xiT​θκ​+βκ​)exp(xiT​θc​+βc​)​)xi​∂βc​∂J​=−N1​i=1∑N​(1[yi​=c]−∑κ=1C​exp(xiT​θκ​+βκ​)exp(xiT​θc​+βc​)​)​
Block

These gradients will give us the direction of the weights and biases that will cause the steepest descent towards a local minima.

  • Step 3: Update parameters:
θcnew=θc+α∂J∂θcβcnew=βc+α∂J∂βc\begin{gather*} \theta_c^{\text{new}} = \theta_c + \alpha \frac{\partial J}{\partial \theta_c} \quad \\[15pt] \beta_c^{\text{new}} = \beta_c + \alpha \frac{\partial J}{\partial \beta_c} \end{gather*}θcnew​=θc​+α∂θc​∂J​βcnew​=βc​+α∂βc​∂J​​
Block

Where α\alphaα denotes the learning rate. We perform step 2 and 3 for all logits from 111 to CCC.

Often times, regularization is introduced to reduce overfitting, we will focus on L2 regularization, we implement it by simply adding a regularization term into the cost function:

Jreg(Θ,B)=−1Nlog⁡L(Θ,B)+λ2N∑c=1C∥θc∥22J_{\text{reg}}(\Theta, \mathcal{B}) = -\frac{1}{N} \log L(\Theta, \mathcal{B}) + \frac{\lambda}{2N} \sum_{c=1}^C \| \theta_c \|^2_2 \quadJreg​(Θ,B)=−N1​logL(Θ,B)+2Nλ​c=1∑C​∥θc​∥22​
Block

Where λ\lambdaλ is a constant that represents the regularization strength. This will affect the weights of the model, large λ\lambdaλ causes the weights to be closer to 0 and needs to be tune strategically to properly reduce overfitting. While the biases updates remain unchanged, our weights updates will be affected:

θcnew=θc+α∂J∂θc−λNθc\theta_c^{\text{new}} = \theta_c + \alpha \frac{\partial J}{\partial \theta_c} - \frac{\lambda}{N} \theta_c \quadθcnew​=θc​+α∂θc​∂J​−Nλ​θc​

Binary Logistic Regression

When there are C=2C = 2C=2 classes, the softmax function is reduced to a special case called the Sigmoid Function, for simplicity we let yi∈{0,1}y_i \in \{ 0, 1 \}yi​∈{0,1}:

1exiTθ1+β1+exiTθ2+β2(exiTθ1+β1exiTθ2+β2)=1exiT(θ1−θ2)+β1−β2+1(exiT(θ1−θ2)+β1−β21)=(exiT(θ1−θ2)+β1−β21+exiT(θ1−θ2)+β1−β211+exiT(θ1−θ2)+β1−β2)\begin{aligned} & \frac{1}{e^{x_i^T \theta_1 + \beta_1} + e^{x_i^T \theta_2 + \beta_2}} \left( \begin{array}{c} e^{x_i^T \theta_1 + \beta_1} \\ e^{x_i^T \theta_2 + \beta_2} \end{array} \right) \\[15pt] &= \frac{1}{e^{x_i^T(\theta_1 - \theta_2) + \beta_1 - \beta_2} + 1} \left( \begin{array}{c} e^{x_i^T(\theta_1 - \theta_2) + \beta_1 - \beta_2} \\ 1 \end{array} \right) \\[15pt] &= \left( \begin{array}{c} \frac{e^{x_i^T(\theta_1 - \theta_2) + \beta_1 - \beta_2}}{1+e^{x_i^T(\theta_1 - \theta_2) + \beta_1 - \beta_2}} \\ \frac{1}{1+e^{x_i^T(\theta_1 - \theta_2) + \beta_1 - \beta_2}} \end{array} \right) \end{aligned}​exiT​θ1​+β1​+exiT​θ2​+β2​1​(exiT​θ1​+β1​exiT​θ2​+β2​​)=exiT​(θ1​−θ2​)+β1​−β2​+11​(exiT​(θ1​−θ2​)+β1​−β2​1​)=​1+exiT​(θ1​−θ2​)+β1​−β2​exiT​(θ1​−θ2​)+β1​−β2​​1+exiT​(θ1​−θ2​)+β1​−β2​1​​​​
Block

Let θ′=θ2−θ1\theta^{'} = \theta_2 - \theta_1θ′=θ2​−θ1​ and β′=β2−β1\beta^{'} = \beta_2 - \beta_1β′=β2​−β1​, we have:

11+exp⁡(−(xiTθ′+β′)) ;1−11+exp⁡(−(xiTθ′+β′))\frac{1}{1+\exp(-(x_i^T \theta^{'} + \beta^{'}))} \space ; \quad 1 - \frac{1}{1+\exp(-(x_i^T \theta^{'} + \beta^{'}))}1+exp(−(xiT​θ′+β′))1​ ;1−1+exp(−(xiT​θ′+β′))1​
Block

Which denotes the probability of class 0 and 1 respectively, notice that both of the expressions above still sum up to 1. Therefore, when C=2C = 2C=2, we only have to optimize for 1 set of weights θ′\theta^{'}θ′ and a single bias β′\beta^{'}β′. Given dataset X={(xi,yi)}i=1NX = \{ (x_i, y_i) \}_{i=1}^NX={(xi​,yi​)}i=1N​ where xi∈Rnx_i \in \mathbb{R}^nxi​∈Rn and yi∈{0,1}y_i \in \{ 0,1\}yi​∈{0,1}, the Binary Logistic Regression model or simply Logistic Regression model is represented as:

P(y∣x,θ,β)=(σ(z))y(1−σ(z))1−y ;z=xTθ′+β′P(y \mid x, \theta, \beta) = (\sigma(z))^y(1-\sigma(z))^{1-y} \space ; \quad z = x^T\theta^{'} + \beta^{'} \quadP(y∣x,θ,β)=(σ(z))y(1−σ(z))1−y ;z=xTθ′+β′

  • Where the weights θ′={θ1,θ2,…,θn}\theta^{'} = \{\theta_1, \theta_2, \ldots, \theta_n\}θ′={θ1​,θ2​,…,θn​} and bias β′∈R\beta^{'} \in \mathbb{R}β′∈R are the model’s parameters.
  • The expression σ(z)=11+exp⁡(−z)\sigma(z) = \frac{1}{1+\exp(-z)}σ(z)=1+exp(−z)1​ denotes the sigmoid function, and z=xTθ′+β′z = x^T\theta^{'} + \beta^{'}z=xTθ′+β′ denotes a linear combination of the input xxx and the weights and bias, this function tends to 000 as z→−∞z \rightarrow -\inftyz→−∞ and tends to 111 as z→+∞z \rightarrow +\inftyz→+∞, and σ(z)+(1−σ(z))=1\sigma(z) + (1-\sigma(z)) = 1σ(z)+(1−σ(z))=1.
